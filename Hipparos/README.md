# Hipparcos Star Catalog Analysis 🌟

Analysis of the Hipparcos astrometric catalogue observed by ESA's Hipparcos space mission (1989-1993).

## Data
Data was taken from [Vizier](https://vizier.cds.unistra.fr/viz-bin/VizieR-3?-source=I/239/hip_main)

## 📈 Key Analyses
+ Hertzsprung–Russell diagram
+ Spectral Types
+ Temperature
+ Proper Motion of stars
+ Parallax
+ Histogram on stellar period
